# GitHub upload instructions

1. Extract the ZIP locally.
2. Open GitHub and create a public repository named `iam-vmware-lab` (or use your existing portfolio repository).
3. Select **Add file > Upload files** in the repository.
4. Upload the folder contents under `06-privileged-access-management/`, retaining `README.md`, `scripts/`, `docs/`, and the completion sheet.
5. Review the files for credentials, secrets, personal identifiers, and unredacted logs before committing.
6. Use commit message `Add IAM Project 06 privileged access delegation validation`.
7. Open the README on GitHub to confirm paths and Markdown render correctly.
8. Add a link to Project 06 from your portfolio root README.

Do not upload sensitive screenshots or domain backups.
